# Fundamentos de marca

**Referências:** Brandbook Argos Soluções, 28/09/2026 (9 páginas); Argos Soluções Brand Guidelines, agosto/2026 (25 páginas).

## Posicionamento

> A Argos Soluções desenvolve tecnologia e inteligência de dados para tornar a gestão de organizações públicas e privadas mais clara, segura e eficiente.

**Assinatura:** Onde dados se tornam decisão.  
**Mensagem de entrega:** Gestão, controle e resultado.

## Cores oficiais

| Nome         | HEX       | Uso                 |
| ------------ | --------- | ------------------- |
| Argos Navy   | `#000F37` | Base e títulos      |
| Argos Orange | `#FF5D00` | Ações e destaques   |
| Branco       | `#FFFFFF` | Fundos              |
| Argos Gray   | `#D1D2D2` | Divisórias          |
| Argos Rust   | `#B02500` | Destaque secundário |
| Tint Laranja | `#FFE7D6` | Apoio               |
| Tint Navy    | `#DDE2EC` | Apoio               |

Navy = base e confiança; Orange = ação/destaque, **com moderação**; Gray = plano de fundo neutro e divisórias; Rust = destaque secundário, dados e alertas. Valores RGB/CMYK (guia ago/2026): Navy 0,15,55 / 100,84,0,78; Orange 255,93,0 / 0,64,100,0.

**Contraste (calculado, WCAG):** Navy sobre Orange 6,1:1 (usar texto navy em botão laranja; branco sobre laranja = 3,1:1, **não usar** para texto normal); Orange como texto sobre branco 3,1:1 (somente texto grande/ícones); Branco sobre Rust 6,8:1.

## Logo

- Não distorcer, girar, espelhar, recolorir, aplicar sombra ou contorno.
- Versão completa: mínimo digital de 96 px de largura; símbolo isolado: mínimo de 32 px.
- Proteção: 1X em torno da marca completa (X = altura da letra A); símbolo isolado: 1,5X medido pela largura do olho.
- Fundos permitidos: navy, branco, cinza claro ou laranja. Navy/laranja exigem versão branca; branco/cinza claro, versão a cores. No demo, o logo colorido fica sobre placa branca dentro da barra navy como solução provisória até existir a versão branca.
- Não usar o logo mais de uma vez na mesma peça nem como moldura de imagens.
- Para fundos escuros, o guia de agosto exige versão monocromática branca, que **não foi fornecida**. Não simular invertendo cores do JPEG.
- O arquivo original enviado possui fundo claro. Não presumir transparência por causa do nome do arquivo.

## Tipografia

Fonte indicada: Argos Sans Bold (somente títulos e destaques, sempre Bold) e Regular (somente corpo). Texto sempre alinhado à esquerda; títulos em CAIXA ALTA, demais textos em frase (só a primeira letra maiúscula); entrelinha: títulos 100%, subtítulos 115%, corpo 140% (`--lh-*`). Evitar pesos acima de 700. Como arquivos não foram fornecidos, Inter/Arial são alternativas técnicas provisórias. Não recriar o wordmark digitando ARGOS.

## Escrita

Clara, objetiva, responsável. Não anunciar recursos planejados como concluídos. Verificar métricas, clientes e contratos antes de publicar.
